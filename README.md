# Dictados

Melodic dictation generator **and musical improviser** over chord progressions.

This project has two main capabilities:

1. **Dictation generator** — generates MIDI ear-training exercises using triadic
   arpeggios (the original feature, configured via YAML).
2. **Musical Improviser** — generates two-track MIDI files with a chord backing
   track and an intelligent melodic improvisation line.

---

## Musical Improviser

The improviser lives in `src/dictados/improviser/` and is invoked via:

```bash
python -m dictados.improviser.main [OPTIONS] [TEXT]
```

### Input modes

| Mode | Command |
|------|---------|
| Text input (inline) | `python -m dictados.improviser.main "4 compases de Am C Dm E"` |
| Text with options | `python -m dictados.improviser.main "2 ruedas de Am C Dm E, swing, 130bpm"` |
| MIDI file input | `python -m dictados.improviser.main --input input/my_chords.mid` |
| Interactive mode | `python -m dictados.improviser.main` |

### Text input examples

```bash
# 4 measures, chords Am C Dm E, default 120 BPM
python -m dictados.improviser.main "4 compases de Am C Dm E"

# 2 rounds of Am C Dm E at 130 BPM with swing feel
python -m dictados.improviser.main "2 ruedas de Am C Dm E, swing, 130bpm"

# Plain list of chords
python -m dictados.improviser.main "Dm G7 Cmaj7 Am"

# Reproducible output with a fixed seed
python -m dictados.improviser.main "Am C Dm E" --seed 42
```

### MIDI file input

Place your chord MIDI file in the `input/` folder:

```bash
python -m dictados.improviser.main --input input/my_chords.mid
```

### Command-line options

| Flag | Description |
|------|-------------|
| `--tempo BPM` | Override tempo in BPM |
| `--rounds N` | Repetitions of the progression |
| `--seed INT` | Random seed for reproducible output |
| `--output PATH` | Output MIDI file path |

### Output

The generated MIDI file (saved to `01_midi_files/output/`) contains **two tracks**:

- **Track 1 — Chord backing** (Acoustic Grand Piano): block chords held for
  the full measure, acting as a harmonic metronome.
- **Track 2 — Melodic improvisation** (Flute): a single-voice melodic line
  generated by one of six improvisation strategies:

| Strategy | Description |
|----------|-------------|
| Arpeggio | Directed arpeggio with rhythmic variation |
| Scale walk | Stepwise motion along the chord's modal scale |
| Lick | Pre-composed phrase from a library of 20 licks, transposed to the chord |
| Approach tone | Chromatic/diatonic approach to chord tones (tension → resolution) |
| Motif development | Develops a short motif via retrograde, inversion, transposition |
| Weighted random | 60 % chord tones · 30 % scale tones · 10 % chromatic |

The engine alternates between "call" and "response" strategies across measures
and enforces voice-leading constraints (max leap = 12 semitones, range C3–C6).

## Dictation generator (original feature)

Generates MIDI ear-training exercises from a YAML configuration:

```bash
python -m dictados config.yaml
```
